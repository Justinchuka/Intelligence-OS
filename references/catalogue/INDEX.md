# Catalogue index

10 categories x 10 modules = 100 catalogue modules. Selecting from the catalogue counts toward the **15 active custom features** limit (`limits.max_custom_features`). Modes: D = discovery, T = tracking, A = analysis. Module definitions are in the category files; `modules.json` is the machine-readable mirror used by `ios.py module add --catalogue <id>`.
